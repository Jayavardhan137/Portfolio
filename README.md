# Jayavardhan Malamanti — Cinematic Developer Portfolio

A cinematic, editorial-style personal portfolio website built for **Jayavardhan Malamanti**, specializing in Artificial Intelligence & Machine Learning and Full-Stack Engineering.

Inspired by award-winning creative developer portfolios, featuring high-contrast monochrome typography, volumetric spotlight lighting, 3D interactive project displays, and smooth animations.

---

## ✦ Key Features & Design System

- **Monochrome Editorial Palette**: Obsidian blacks (`#050505`), gallery stark whites, and graphite tones with volumetric spotlight cones.
- **Atmospheric Preloader**: Minimalist initial entrance animation featuring initials `JM.` with glowing counter.
- **Volumetric Hero & Silhouette**: Massive typography `"BUILDING BEYOND THE ORDINARY"`, ambient spotlight tracking, and custom monochrome silhouette composition.
- **Cinematic About Section**: Dedicated spotlight feature card (*"Turning visionary ideas into fast, distinctive digital experiences"*) and structured focus narrative.
- **Experimental Typography Skills Explorer**: Interactive category matrix with ghosted typographic watermarks (`INTELLIGENCE`, `INTERFACES`, `SERVICES`, `WORKFLOW`).
- **Curated Work Showcase with 3D Drum View**:
  - **Project 01 — QFLOW AI**: Intelligent Queue Management Platform with QR token booking, AI voice synthesis, and real-time tracking.
  - **Project 02 — STUDYASSISTANT**: Context-aware RAG learning assistant with vector retrieval and dynamic AI personas.
  - **3D Drum Showcase Mode**: Interactive rotating hexagonal drum wheel inspired by high-end creative agency showcases.
- **Interactive Journey Timeline**: Scroll-revealed engineering milestones and academic trajectory in B.Tech CSE (AI & ML).
- **Editorial Services Accordion**: High-contrast service drawers with structured deliverables and direct inquiry triggers.
- **Dramatic Contact Experience**: Huge typography `"LET'S BUILD SOMETHING EXTRAORDINARY"`, one-click email copy pill, functional inquiry form, and magnetic social links.
- **Sound Synthesis**: Atmospheric Web Audio API synthesizer for tactile clicks and subtle mechanical feedback (toggleable in navigation).
- **Smooth Physics**: Lenis smooth scroll provider, custom magnetic buttons, and responsive trailing cursor.

---

## ✦ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 15 (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Motion & Interactions**: [Framer Motion](https://www.framer.com/motion/) & [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons**: [Lucide React](https://lucide.dev/) & Custom Monochromatic SVGs
- **Audio**: Web Audio API Procedural Synthesizer

## ✦ Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
npm run start
```
